# Japanese credits font

NotoSansJP-Regular.ttf is the unmodified NotoSansJP[wght].ttf variable font
distributed by Google Fonts, renamed only for the launcher's asset lookup.
Source: https://github.com/google/fonts/tree/main/ofl/notosansjp
Downloaded 2026-09-24. License: accompanying NotoSansJP-OFL.txt (SIL OFL 1.1).
The game packages this font locally; no system-font or network dependency at run time.
