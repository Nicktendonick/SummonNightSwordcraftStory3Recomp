# Reverse-engineering references

These projects are upstream references, not vendored source dependencies:

- `mstan/MinishCapRecomp`: game-repository and recomp-ui integration pattern.
- `jiangzhengwenjz/csm3`: matching Japanese decompilation; symbol evidence and
  EEPROM behavior.
- `stickteo/snsc3gfx`: graphics editing/repacking research.
- `Cofflag/csm3sc`: script tooling and research.
- `KurobaM/csm3-cg-verify`: modified-graphics verification tooling.

Only independently generated metadata belongs in this repository. Do not copy
ROM data, extracted art, scripts, or decompilation source into the port.
